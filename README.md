# DishaTara

An early static prototype for DishaTara, an AI astrology companion. It presents a bilingual English and Hindi landing page with a birth-details flow and demo question experience.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Current scope

- Bilingual interface: English and Hindi
- Client-side demo flow only
- No astrology calculations, AI service, database, or server-side storage

## Next milestone

Connect a verified chart-calculation engine, then build an API layer for the reading and question-answering experience. Do not send user birth details to external services until a privacy policy and consent flow are in place.

## Disclaimer

Astrology content is for reflection and entertainment. It is not medical, legal, financial, or mental-health advice.
